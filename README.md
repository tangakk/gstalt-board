# Методы для постов

### /create POST
Создаёт пост. Если есть JWT в заголовке или куках, использует его. Приоритет у заголовка. Возвращает ОК или ошибку
```
Content-Type: multipart/form-data

Body:
Author = Автор поста. По умолчанию Аноним. Максимум 20 символов
Text = Собственно текст поста
Data = Данные файлика, пока что максимум 2 МБ
Parentid = Айди поста-родителя
Board = /имя-доски
```
### /get-{id} GET
JSON с постом с соответствующим id. В Data будет base64 строка.
### /{board}/get-{offset}-{n} GET
JSON с {n} последних постов на доске /{board}, начиная с {offset}. Только посты с ParentId=0
### /get-responses-{id}-{offset}-{n} GET
Как предыдущее, но ответы к посту, начиная с самого старого.

# Методы для пользователей
### /create-user POST
Создаёт пользователя. Возвращает ОК или ошибку.
```
Content-Type: application/x-www-form-urlencoded

Body:
Name = Имя пользователя
Pass = Пароль
```
### /login POST
Возвращает JWT токен или ошибку.
```
Content-Type: application/x-www-form-urlencoded

Body:
Name = Имя пользователя
Pass = Пароль
```
Ответ:
```
{ "JWT": "многабукав"}
```


# Методы для борд
### /create-board POST
Создаёт доску. Создавать доски могут только суперадмины (их можно задать только через бд, метода нету). На доске нельзя постить, если она не создана. Возвращает ОК или ошибку.
```
Content-Type: application/x-www-form-urlencoded

Body:
Name = /Имя борды маленькой латиницей и цифрами
Description = Описание борды
Admins = Список админов борды через запятую
Mode = цифра от 0 до 4 (0 - открыта всем; 1 - чёрный список; 2 - чёрный список может читать; 3 - белый список; 4 - небелый список может читать)
UsersList = Список тех, кто попадает в список, через запятую
```
### /update-board POST
Обновляет доску. Админов и мод доски могут обновить только суперадмины/создатель борды. Список пользователей могут менять админы борды. Тело как у /create-board
### /{board}/get-board GET
Получить данные о доске. Список пользователей и админов доступен только суперадминам/владельцу/админам борды.
### /get-boards GET
Получить данные обо всех досках. Списки пользователей и админов доступны только суперадминам.
